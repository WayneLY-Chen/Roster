出現「Operation not permitted」的話（跟上面是不同的問題）
════════════════════════════════════════════════════════

訊息長這樣：

    Fatal Python error: init_import_site: Failed to import the site module
    PermissionError: [Errno 1] Operation not permitted:
        '/Users/你的名字/Desktop/Roster/.venv/pyvenv.cfg'

這不是隔離標記，也不是程式壞掉。**桌面、文件、下載**這三個資料夾從
macOS Catalina 起受系統保護，終端機（或 Roster.app）沒有被授權的話，
讀得到檔案名字、讀不到內容——所以程式看起來「安裝好了」，一啟動就死。

兩個解法，選一個：

● 解法一：授權（Roster 可以留在桌面）

  系統設定 → 隱私權與安全性 → 檔案與資料夾
    → 找到「終端機」→ 打開「桌面資料夾」

  清單裡沒有「終端機」的話：
  系統設定 → 隱私權與安全性 → 完整取得磁碟權限 → ＋ → 選「終端機」

  授權之後**要把終端機整個結束再重開**（⌘Q），設定才會生效。

  用 Roster.app 啟動的話，要授權的是「Roster」，不是「終端機」。

● 解法二：把 Roster 移出桌面（不必動任何系統設定）

  在「訪達」把整個 Roster 資料夾拖到你的「使用者主目錄」——側邊欄上
  有你名字的那一個（不是桌面、不是文件）。主目錄的最上層不受這個保護。

  移動之後如果原本有 Roster.app，請重新執行一次「建立App.command」。

從 v1.17.1 起，安裝、啟動、命令列、診斷四個檔案都會自己認出這個情況，
直接把上面這段印出來，不會再讓你看到那串 Python 訊息。

雙擊時被 Gatekeeper 擋下來
════════════════════════════════════════════════════════

雙擊「安裝.command」出現這個視窗的話：

    「Apple 無法驗證「安裝.command」是否為惡意軟體。
      它可能會損害你的 Mac 或危害你的隱私權。」

這不是程式壞掉，也不是真的偵測到什麼東西。macOS 會替**所有**從瀏覽器
下載的檔案貼上一個「下載自網路」的隔離標記，只要沒有付費的 Apple 開發者
簽章，就一律顯示這個訊息。

macOS 15 (Sequoia) 開始，以前那個「按右鍵 →『打開』」的做法已經被 Apple
拿掉了，所以右鍵沒有用。


────────────────────────────────────────────────────────
最快的解法（一行指令，一次解決全部）
────────────────────────────────────────────────────────

1. 打開「終端機」
   （聚焦搜尋 ⌘ + 空白鍵 → 輸入「終端機」→ Enter）

2. 輸入這一段，**最後留一個空白**，先不要按 Enter：

       xattr -dr com.apple.quarantine

3. 把 Roster 這個資料夾（外層那個，不是 macOS 資料夾）
   直接**拖進終端機視窗**。路徑會自動填好。

4. 按 Enter。沒有任何訊息就是成功了。

5. 回去雙擊「安裝.command」，這次就會正常執行。


────────────────────────────────────────────────────────
其他做法
────────────────────────────────────────────────────────

● 用 git 下載，完全不會遇到這個問題

  git clone 下來的檔案不算「從網路下載」，不會被貼標記：

       git clone https://github.com/WayneLY-Chen/Roster.git

  下載完直接雙擊就能用。


● 不想動終端機的話

  雙擊「安裝.command」被擋掉之後，馬上到
  系統設定 → 隱私權與安全性 → 往下捲，
  會看到「已阻止使用『安裝.command』」和一個「仍要打開」按鈕。

  缺點：每一個 .command 檔都要各按一次。


● 終端機視窗跑完不會自己關掉

  這是「終端機」App 自己的預設行為，不是程式沒結束。要改的話：

      終端機 → 設定… → 描述檔 → Shell
      →「當 Shell 結束時：」選「若 Shell 正常結束則關閉視窗」


● 安裝完 Roster.app 沒出現、或點了打不開

  先看 logs/啟動失敗.log（Roster 資料夾裡的 logs 資料夾）。
  每一次點 Roster.app 都會在裡面寫一行時間，所以：

      有時間那一行 → App 的外殼有跑到，失敗在後面，同一個檔案裡會寫原因
      完全沒有那一行 → 連外殼都沒被執行到，問題在 macOS 這一端
                        （執行權限、下載隔離標記、或 App 沒建成功）

  接著雙擊同一個資料夾裡的「診斷.command」，它會把每一步的狀況印出來，
  包含重新建立一次 Roster.app 的完整錯誤訊息。把整段輸出、
  連同上面那個紀錄檔一起貼給我。


● 只跑一次安裝就好

  在終端機裡用 bash 執行，不會經過 Gatekeeper：

       bash "把安裝.command拖進來"

  安裝程式跑完會自動解除整個資料夾的隔離標記，
  之後「啟動.command」與 Roster.app 就都能直接雙擊了。
