# 寄送開發信

設定 Gmail、寫樣板、加附件、產生名單、寄出，以及內建的保護機制。

[← 回到 README](../README.md)

---

## 第一步：產生 Google 應用程式密碼

**不要**使用你的 Google 帳號密碼。

1. 到 Google 帳戶 → 安全性 → 開啟「**兩步驟驗證**」
2. 前往 <https://myaccount.google.com/apppasswords>
3. 建立一組新的應用程式密碼，複製那 16 碼

## 第二步：在程式裡設定

到「**設定**」頁 →「**Gmail 帳號**」區塊，填入帳號與應用程式密碼，
按「**儲存到系統**」，再按「**測試連線**」。

密碼會存進 **Windows 認證管理員**（macOS 是 Keychain），
**不會**寫進專案資料夾裡的任何檔案。

## 第三步：開啟寄信功能

到「**郵件**」頁的「寄件狀態」區塊，把「**啟用郵件寄送**」打開。

旁邊還有一個「**實際寄出**」開關：

- **關著**（預設）＝演練模式。按「開始寄送」也只會寫進資料庫並標記為演練，**不會真的寄**
- **打開**＝真的寄。切換時會跳出確認，因為寄出去的信收不回來

## 第四步：寫信件樣板

到「**郵件**」頁左側。主旨直接打，內文按「**放大編輯**」開一個大視窗來寫。

放大視窗裡可以用粗體、斜體、底線、標題、項目符號、連結、插入圖片。

有格式的信會以 **HTML** 寄出，並且**同時附一份純文字版**——不是每個信箱都顯示
HTML，而且純 HTML 的信比較容易被判定成垃圾郵件。圖片以 **CID 附件**內嵌，
因為 Gmail 會把 `data:` URI 的圖片擋掉。

可用變數：`{company_name}`、`{english_name}`、`{contact_person}`、`{industry}`、
`{products}`、`{email}`、`{phone}`、`{website}`、`{city}`

打錯的變數（例如 `{compnay_name}`）會直接報錯，不會把它原樣寄出去。

## 第五步：加附件（選用）

樣板下方有「**附件**」區塊。按「**加入附件**」選檔案，程式會複製一份到
`attachments/` 資料夾——之後就算原檔被移走或刪掉，也不影響寄送。

附件用**勾選**的方式決定這次要不要帶：資料夾裡可以長期放著型錄、報價單、
公司簡介，每次活動只勾要用的那幾個，不用為了這次不寄就刪掉檔案。

單封信的所有附件**合計**上限 20 MB。超過的話「產生名單」會被擋下來，
不會等到寄出去才失敗。

按「**管理…**」開附件庫視窗，可以：

| 功能 | 說明 |
|---|---|
| 改顯示名稱 | 把 `2026Q1_catalog_final_v3.pdf` 顯示成「2026 春季型錄」，檔案本身不會被改名 |
| 編輯備註 | 例如「舊版，別再寄了」 |
| 看使用狀況 | 加入時間、寄出過幾次——用來判斷哪些可以清掉 |
| 刪除 | 被自動排程引用時會額外警告 |

直接把檔案丟進 `attachments/` 資料夾也可以，程式下次列出時會自動收編。
反過來把檔案從資料夾拿走的話，那一筆會被標成「檔案不見了」而不是消失——
上面打的顯示名稱與備註都還留著。

> Gmail 的官方上限是 25 MB，但那是編碼後的大小。附件在信件裡是 base64
> 編碼的，體積會膨脹約 1/3，所以原始檔要抓在 20 MB 以內才安全。

## 第六步：產生名單並寄送

1. 在「郵件」頁右側設定篩選條件 → 按「**產生名單**」
2. 名單表會列出每一家公司，以及**會寄／被略過**與略過原因
3. 按「**預覽第一封**」確認實際內容
4. 先按「**演練（不寄出）**」跑一次，確認統計數字合理
5. 確認無誤後把「**實際寄出**」打開，再按「**開始寄送**」
6. 會跳出二次確認，寫明要寄給幾家、用哪個帳號、間隔幾秒

## 內建的保護機制

| 機制 | 說明 |
|---|---|
| **請勿聯絡名單** | 優先於一切，且沒有任何設定可以覆寫 |
| 每日上限 | 依當天實際寄出的封數計算 |
| 寄送間隔 | 每封之間強制等待，避免被 Gmail 判定為垃圾郵件來源 |
| 不重複寄送 | 同一家公司在設定天數內不會再收到 |
| 只寄給驗證過的信箱 | 可關閉，但預設開啟 |
| 退訂說明 | 強制附加在每封信末尾，並加上 `List-Unsubscribe` 標頭 |
| 預設演練模式 | 新環境第一次跑一定是演練，不會意外寄出 |
| 完整稽核紀錄 | 每封信在寄出**前**就寫入資料庫 |

有人回信要求退訂時，到該公司的詳細視窗勾選「請勿聯絡」，之後永遠不會再寄給他。
