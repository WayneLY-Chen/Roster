# 整理與匯出名單

抓回來之後：欄位、名單品質、清理、去重、匯入匯出。

[← 回到 README](../README.md)

## 每一家公司會存哪些欄位

| 欄位 | 說明 |
|---|---|
| 公司名稱 | 唯一必填的欄位 |
| 英文名稱 | 台灣的公協會名錄普遍會列 |
| 統一編號 | 會檢查檢核碼 |
| 電子信箱 | 會驗證格式與收信網域 |
| 電話 / 傳真 | 會正規化（全形轉半形、去掉 +886） |
| 公司網址 / 公司地址 | 網址會自動補通訊協定；地址會抓出縣市 |
| 產業 | 名錄多半是一個分類一頁，可以在來源上設定預設值 |
| 主要產品 | 名錄上的「代理廠商及代銷產品」之類 |
| 聯絡人 | 「王小姐」「業務部 張經理」這種寫法都存得進去 |
| 登記狀態 / 資本額 | 由[補公司登記資料](爬取.md#這家公司還在不在)填入 |

加上業務階段、優先度、狀態、標籤、追蹤日期、備註。
在「公司」頁按「編輯」開啟詳細資料視窗即可修改，沒有資料的欄位會顯示
「（無資料）」而不是留白。

**上面裝不下的欄位不會被丟掉。** 每個名錄列的東西都不一樣——旅行公會列
「會員代表」「入會年月日」「註冊編號」，化工公會列「代理廠商及代銷產品」。
這些會照原本的名稱一起存下來，在詳細資料視窗的「其他欄位」區看得到、也能
自己新增或修改。匯出時每個各佔一欄，匯入時對應不到固定欄位的欄也收得回來。

## 先聯絡哪一批：名單品質

一份幾百筆的名單，每一列的可用程度差很多。「公司」頁的「品質」欄是一個 0 到
100 的分數，篩選列右邊的「排序」預設就是照它排，把真的聯絡得上的排在前面。

| 看什麼 | 配分 |
|---|---|
| 電子信箱 | 40（MX 驗證過）／28（還沒驗）／5（驗不過） |
| 電話 | 20 |
| 資本額 | 15（要先做過「補公司登記資料」） |
| 資料新舊 | 10（一個月內）／7（三個月）／4（一年） |
| 網站、聯絡人、地址、統一編號 | 5 / 5 / 3 / 2 |

登記狀態已經是解散、撤銷、廢止的，以及標記過「不再聯絡」的，一律壓到最低
——資料再完整都不該排在前面。

打開一家公司的詳細資料，「名單品質」那一區會把分數怎麼來的攤開寫，所以看得出
「要往上拉的話下一步該補什麼」。

分數是每次查詢時算的，不存進資料庫：裡面有「資料多新」這一項，存成欄位的話
今天算的分數明天就不對了。

## 資料清理

抓進來的原始文字會依序經過四關：

1. **正規化** — 全形轉半形、`+886` 電話前綴、`台`/`臺` 統一、網址補上通訊協定並移除
   `utm_*` 追蹤參數、從 `mailto:` 與「姓名 &lt;信箱&gt;」形式解出乾淨信箱
2. **驗證** — 信箱語法、拋棄式信箱網域、電話位數、網址格式、統一編號檢核碼
3. **MX 查詢** — 確認該網域是否真的收信；每個網域只查一次並快取
4. **去重**

## 去重

每筆資料會算出一把帶前綴的識別鍵，強度由高到低：

| 形式 | 依據 | 信心 |
|---|---|---|
| `tax:12345678` | 統一編號 | 精確 |
| `mail:a@b.com` | 電子信箱 | 精確 |
| `np:名稱｜電話` | 名稱＋電話 | 高 |
| `nw:名稱｜網域` | 名稱＋網站 | 高 |
| `n:名稱` | 僅名稱 | 中 |

寫入時不只比對這把鍵，還會分別用統編、信箱、名稱＋電話、名稱＋網域去找既有資料
——同一家公司可能在第 1 頁只露出電話、第 2 頁才有統編，算出來的鍵並不一樣。

**合併時只補空欄位，不會覆寫你手動整理過的內容。**

漏網之魚可以在「公司」頁按「**尋找重複**」，逐組確認後合併。

## 依收集日期檢視與整批刪除

「公司」頁的「**收集日期**」下拉選單會列出每一天各收集了幾家。你是一批一批
爬的，所以「哪一天爬的」通常比筆數區間更貼近你心裡的分組方式。

選了某一天之後，右上角的「**刪除該日全部**」會啟用——某次爬取的設定寫錯、
抓回一堆垃圾時，這是整批清掉的入口，連同底下的聯絡人、活動記錄與附件一起
刪除。選著「全部」時這顆按鈕是停用的，避免誤按清空整個資料庫。

**這個動作無法復原**，動手前建議先到「設定」頁建立一份備份。

## 匯入

「**匯入**」頁支援 CSV / Excel / JSON。旁邊有「**下載範例檔**」，
產生的 Excel 有兩個分頁：第一頁是可以直接填的空表，第二頁是逐欄說明。
填好存檔，回到「匯入」頁選這個檔案就能匯進去。

只有「公司名稱」是必填。標題可以用多種常見寫法，對應不到固定欄位的欄會照
原本的標題保留成「其他欄位」，並在匯入結果裡列出來。

## 匯出

「**匯出**」頁可以選格式（Excel / CSV / JSON）、下篩選條件、勾選欄位、
指定檔名或留空自動命名到 `output/`。

Excel 會自動凍結標題列、加上篩選、依內容調整欄寬。
CSV 預設用 `utf-8-sig`，否則繁體中文版 Excel 會把中文顯示成亂碼。
