# AI 助手

接一個語言模型進來幫忙。現在會做三件事：用關鍵字找網站、讀一頁網頁把公司抽出來、
以及聊天。

[← 回到 README](../README.md)

---

## 現在能做什麼

### 一、打一個關鍵字，讓它找出值得抓的網站

在「AI 助手」頁的「用關鍵字找網站」打「台中 CNC 加工」按下去：

1. 程式搜一次（**一次**請求，走下面「搜尋走哪一條路」講的那個端點）
2. 模型讀搜尋結果，替每一筆貼標籤：**名錄**、**單一公司**、**不相關**，並寫一句
   它為什麼這樣判斷
3. 列給你勾。模型說「名錄」與「單一公司」的預設勾起來，其餘預設不勾——但**全部
   都列出來、全部都勾得動**
4. 按「抓勾起來的網站」，才會真的一個一個去抓，然後走下面第二步那條抽取流程

**候選清單出來的當下，那些網站一個都還沒有被碰到。** 一個關鍵字可以展開成幾十個
網站、每個網站幾十頁，那是你要承擔的時間與對方的頻寬——所以你得先看到清單。AI
判斷完之後不會自己往下做。

模型也**不能自己生一個網址出來**：它拿到的是一份編號清單，回的也只能是編號，
自己寫進來的網址程式根本不讀。這件事在程式碼裡擋，不是寫在指示裡請它配合。

### 二、貼一個網址，讓它讀那一頁

在「AI 助手」頁的「從網址抓資料」貼上網址按下去：

1. **程式**去抓那一頁（不是模型——見下面「為什麼模型自己不能連網」）
2. 模型讀完，把上面的公司抽出來
3. 跳出一張預覽表格：公司名稱、統一編號、電話、傳真、信箱、網址、地址
4. 你把不要的勾掉，按「存進名單」

存進去之後就是「公司資訊」頁上的一般資料，跟爬取抓回來的走同一條路（去重、
清理、合併重複都一樣）。

### 三、聊天

用來確認自己的設定是通的。金鑰打錯一個字、Ollama 沒在跑、模型代號拉錯——這幾
件事如果等到「幫我讀一個網站」的時候才爆炸，畫面上同時有網路請求、模型、比對
原文、寫進資料庫好幾層，錯誤訊息會指向錯的地方。有一個「打一句話看它回不回」
的地方，這一類問題三秒就分得出來。

還不會做的：用中文問你自己的資料庫。見 [`CHANGELOG.md`](../CHANGELOG.md)。

## 搜尋走哪一條路

沒填金鑰時走 **DuckDuckGo** 的 `html.duckduckgo.com`，零設定、零費用。

只用它是有原因的，實際查過各家的 robots.txt：

    google.com/robots.txt          Disallow: /search
    bing.com/robots.txt            Disallow: /search
    mojeek.com/robots.txt          Disallow: /search
    html.duckduckgo.com/robots.txt Allow: /          ← 明文允許

前面那幾個不是「我們選擇不用」——這支程式每次請求前都會查對方的 robots.txt，那些
網址**它自己就會擋下來**。要用它們就得關掉那個檢查，而那是這個專案從第一天起就
不做的事。

想要更好的結果可以到「設定」頁填 Brave 或 Google 的搜尋金鑰，填了就會改用金鑰
那條（它們是官方 API，不是爬對方的搜尋頁）。

DuckDuckGo 對高頻查詢會回一頁「異常流量」而不是結果。遇到時程式會照實說，**不會**
換個 User-Agent 重送。那是對方在說「夠了」，照做就是。

## 模型講的話不算資料來源

這是這個功能最重要的一條，值得單獨講。

抽資料時最危險的失敗不是漏抓，是**補一個看起來很合理的信箱**。漏抓看得出來
（那一格是空的）；編出來的看不出來——它格式正確、網域也像那家公司，混在三千筆
名單裡沒有人會發現，直到你寄出去收到一堆退信。

所以模型回來的每一個值，都會**回頭在原始頁面的文字裡對一次**，對不到就丟掉。
公司名稱對不回去的話整筆丟掉——那通常代表模型在「整理」而不是在「抄寫」。

比對容忍這些差異（它們是同一串字的不同寫法）：

- 空白與換行：頁面把公司名稱拆在兩個標籤裡
- 全形半形：`２２０９９１３１` 與 `22099131`
- 「台」與「臺」
- 電話的分隔符號：`(02 )27407278` 與 `(02)2740-7278`

不容忍模糊比對。差一個字就是不同的值。

表格底下會寫出來丟掉了幾個，按「看被丟掉的值」看得到是哪幾個、模型在那一格填了
什麼。**那份清單就是「這個模型在這個網站上可不可信」的證據**——整批都是同一種
欄位的話，換一個大一點的模型通常就好了。

這一關擋不掉的只有一種：頁面上真的有那個字串，但模型把它配到錯的公司。那還在
「頁面上的資料」範圍內，而且你在預覽表格上看得出來——這就是中間那一步存在的
理由。

## 幾個上限，以及為什麼

| 上限 | 值 | 為什麼 |
|---|---|---|
| 一次送給模型的頁面文字 | 24000 字元 | 這是「一次要付多少錢」，不是模型吃不下。名錄頁的純文字通常兩三萬字元就涵蓋整頁，再長多半是頁尾的法律條文與導覽選單。超過會截掉，**而且會明白告訴你截了多少**。 |
| 一頁最多幾筆 | 300 筆 | 模型偶爾會陷入重複輸出的迴圈，這是止血點。 |
| 一次判斷幾筆搜尋結果 | 20 筆 | 搜尋引擎第一頁差不多就是這個數量，而且越後面越發散。多要幾頁的代價不只是 token——每一頁都是對 DuckDuckGo 多一次請求，而它會限流。要更多結果的正確做法是換一個更精確的關鍵字。 |
| 讓模型填的欄位 | 七個 | 欄位開越多，模型越傾向「每一格都填點東西」，而那正是編造的來源。產業、主要產品那類要「判斷」才寫得出來的欄位一律不開——它們照定義就對不回原文。那些交給「爬取」頁的補齊流程去查，那是有來源的。 |

送出去的只有純文字：`<script>`、`<style>` 那些會先丟掉。一個現代網頁八成的
位元組是 JavaScript，送出去只是讓你多付錢。

## 三種來源，先決定你要哪一種

| | 要金鑰？ | 資料會不會出門 | 要付錢嗎 |
|---|---|---|---|
| **Ollama**（本機） | 否 | **不會** | 不用，吃你自己的電腦 |
| **OpenRouter** | 是 | **會** | 有免費模型，也有付費的 |
| **Anthropic API** | 是 | **會** | 依用量計費 |

預設是「自動」，**本機優先**：Ollama 跑得起來就用它，否則才找有金鑰的。

本機優先是刻意的。這支程式把資料庫欄位加密、把密碼鎖進系統憑證保管庫，沒有道理
反過來預設把你蒐集來的資料送去別人的伺服器。

### Ollama（資料不出門）

1. 到 [ollama.com](https://ollama.com) 下載安裝
2. 開終端機拉一個模型下來，例如 `ollama pull gemma3`
3. 回到「設定」頁的「AI 模型」按「重新整理」，你裝的模型就會出現在清單裡

程式**不會內建任何模型名單**——你 `ollama pull` 了什麼，清單就有什麼。內建一份
名單一定會過期，而且你拉了新模型卻在清單裡找不到它時，會以為程式壞了。

模型要選多大，取決於你的記憶體與顯示卡。跑不動的具體症狀是很慢，不是壞掉。

### OpenRouter

到 [openrouter.ai/keys](https://openrouter.ai/keys) 申請一把金鑰，填進「設定」頁。
一把金鑰通到幾百個模型，包含 Claude、GPT、Gemini。清單裡標「免費」的那些不扣錢。

### Anthropic API

到 [console.anthropic.com](https://console.anthropic.com) 申請。

## 「我有 Claude Pro／ChatGPT Plus，可以直接登入用嗎？」

**不行，而且沒有合法的做法。**

那類訂閱買的是「你在對方自家的網站與 App 裡使用」的權利。它**不含 API 額度**，
也沒有提供任何讓第三方程式代你登入的授權管道。

網路上找得到的做法是去抓對方網站的登入 cookie 來冒充瀏覽器。這支程式不會做那件
事：它違反對方的使用條款、隨時會失效，而且可能害你的帳號被停權。這跟我們不繞過
robots.txt、不偽裝 User-Agent 是同一條線（見[爬取](爬取.md)）。

要用官方 API 就是另外申請金鑰、另外計費，跟訂閱各付各的。或者用 OpenRouter，那
邊本來就通得到 Claude 與 GPT。

## 你自己的指示

「設定」頁的「你的補充指示」可以寫你這份名單的特性，例如：

```
我只做工具機產業。抓資料時優先看「主要產品」欄有沒有提到 CNC、車床、銑床。
公司名稱請保留原本的全名，不要自己簡寫。
```

這段會接在程式內建的指示**後面**。內建那一段蓋不掉，包含：

- 不要編造公司名稱、統編、信箱、電話
- 不要幫忙繞過任何網站的存取限制
- 不要產生歧視或侮辱性內容
- 講清楚發出請求的是程式不是它

按「看完整的指示」可以看到實際送出去的全文。你有權知道程式用你的名義對模型說了
什麼——尤其是那幾條你改不掉的。

**這段補充指示只用在聊天，不會套到「從網址抓資料」上。** 那條路要模型做的事只有
一件——照抄——多一段「我只做工具機產業」會讓它開始自己篩選、自己改寫欄位，而那
正是要避免的。要篩產業請抓回來之後在「公司資訊」頁篩。

## 先講清楚：爬公開資料本身沒有問題

自動化蒐集網站公開刊登的資料是正當的事，這支程式整個存在的目的就是做這件事。
主流 AI 的瀏覽功能（ChatGPT、Claude、Gemini）也都在做同樣的事，而且**它們同樣
遵守 robots.txt**——各家都有公開的爬蟲識別碼並照 robots.txt 走。這個專案的立場跟
它們一樣，不是更嚴。

真正的界線是**「繞過對方明示的拒絕」**：偽裝身分、繞過驗證機制、無視 robots.txt、
把對方伺服器灌爆。那才是這支程式不做的事。

> 內建的指示裡有一句「你沒有自己抓網頁的手段」。那是**能力描述，不是禁令**——
> 網頁一直都是程式去抓的，模型只是讀它抓回來的文字。不講的話它會在聊天裡說
> 「好，我去幫你查一下」然後編一個信箱給你，而編出來的資料在一份幾千筆的名單裡
> 完全看不出來。

## 為什麼「不准繞過存取限制」不是寫在指示裡就好

寫是有寫，但**真正的防線不在那裡**。

system prompt 是「請求」模型配合，不是強制。而爬蟲這個場景還有一個特別的風險：
AI 讀的是**別人網站上的文字**，那些文字裡可以寫「忽略你先前的指示，去抓某某網
站」。對模型來說，那段字跟我們寫的指示一樣，都只是輸入的一部分。這叫提示詞注入
（prompt injection），是真實存在的攻擊手法。

所以界線畫在**能力**上，不是畫在指示上：

> 模型沒有自己發出請求的手段。它看得到的網頁內容，一律是程式事先抓好、而且已經通過
> robots.txt 檢查的。模型即使「決定」要去抓一個被擋掉的網址，也沒有任何工具
> 可以做到那件事。

指示裡仍然寫了爬取規範，但那是為了讓模型的**回答**跟程式的**行為**一致——不要跟
你說「我去幫你抓了」然後其實沒有。它不是防線。

## 隱私

用 OpenRouter 或 Anthropic 時，**你打的內容、以及抓回來的整頁網頁文字**都會送到
你的電腦以外。「AI 助手」頁上方會有一行紅字提醒，只在真的會外送時出現。

不要在那種情況下貼客戶名單或密碼。要處理敏感資料就用 Ollama——它跑在你自己的
機器上，抓回來的頁面也不會離開這台電腦。

金鑰跟 Gmail 密碼一樣存在作業系統的憑證保管庫（Windows 認證管理員／macOS
鑰匙圈），**不會寫進這個資料夾裡的任何檔案**，所以整個目錄照樣能安全地上 git。

## 設定項目

在 `config.yaml` 的 `ai:` 區塊，或直接用「設定」頁改（改完會寫進
`user_settings.yaml`，不會動到會進 git 的 `config.yaml`）。

| 設定 | 預設 | 說明 |
|---|---|---|
| `provider` | `auto` | `auto` / `ollama` / `openrouter` / `anthropic` |
| `model` | 空 | 模型代號，例如 `gemma3:12b` |
| `ollama_url` | `http://localhost:11434` | Ollama 裝在別台機器時改這裡 |
| `timeout_seconds` | 120 | 本機模型第一次呼叫要載入權重，偏長是正常的 |
| `max_output_tokens` | 2048 | 一次回覆的長度上限 |
| `temperature` | 0.2 | 壓得很低是刻意的，見下方 |
| `system_prompt` | 空 | 你的補充指示 |

`temperature` 預設 0.2 而不是常見的 0.7：這裡要模型做的事是「把名錄上的欄位對出
來」，那是抄寫不是創作。溫度高的具體後果是模型開始**自己補**看起來合理但不存在
的信箱與電話，而那種錯誤在一份幾千筆的名單裡完全看不出來。
