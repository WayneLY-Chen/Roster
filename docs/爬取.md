# 爬取一個網站

從「不知道名錄在哪一頁」到「抓回來的東西不對怎麼修」。

[← 回到 README](../README.md)

## 不知道名錄在哪一頁？讓程式去找

名錄常常藏在「關於我們 → 組織 → 會員專區」底下三層，從首頁完全看不出來。

到「**爬取**」頁 →「**＋ 自訂網址…**」→ 貼上**這個網站的任一個網址**
（首頁就可以）→ 按「**找名錄…**」。

程式會在同一個網站裡走訪，把看起來像廠商名錄的頁面列出來，附上每頁幾筆、
共幾頁、以及**實際抓到的前幾個名稱**。

只挑一個的話，精靈會接著分析它讓你微調。**也可以勾好幾個**（有「全選」與
「全部取消」）——一個網站常常有各縣市分會、各產業分類好幾份名錄，勾起來的會
逐一分析並各存成一個來源。

判斷依據是內容而不是版面：一個頁面就算有整齊的重複結構、也抓得到信箱，
只要抓出來的是「住家不鏽鋼門檻刮傷，需要修復」這種標題而不是公司名稱，
就不會被當成名錄。

> 這個動作會對別人的網站送出數十次請求，所以按下去之前會先告訴你要讀幾頁、
> 預估多久，讀取頁數有硬上限。網站有 sitemap 的話會優先照著看，
> 那比一頁一頁點連結去猜少掉非常多次請求。

## 用精靈（知道名錄網址時）

1. 到「**爬取**」頁，按「**＋ 自訂網址…**」
2. 貼上目標名錄的網址，按「**分析網頁**」
3. 程式會自己看懂那一頁的結構，並告訴你找到幾筆、抓得到哪些欄位、有沒有下一頁
4. 在「**預覽抓到的資料**」看看內容對不對
5. 填「來源名稱」→ 按「**儲存來源**」或「**儲存並立即爬取**」

**正常情況只要這五步。** 網頁怎麼解析、CSS 選擇器是什麼，都不用管。

舊式的公會名錄（整頁只有表格、沒有一個 class、內容是 Big5）也在支援範圍內：
編碼會自動偵測，「負責人︰」「營業範圍︰」這種寫在文字裡的欄位會被讀出來，
程式沒有對應欄位的（「會員代表」「入會年月日」）則照原名保留。

儲存後這個來源會出現在「來源」下拉選單，之後可以重複使用，也可以被排程自動執行。
設定存在 `custom_sources.yaml`。

### 改一個已經存好的來源

「爬取」頁 →「**管理自訂來源**」→ 選一個 →「**編輯選取的來源**」。

精靈會把當初存的每一格填回來（網址、選擇器、頁碼範圍、要收集哪些欄位、逐項
查詢的範圍……），改完按「儲存來源」就覆蓋它。**不會重新連線到那個網站**——你要
改的是自己當初的決定，那些設定檔裡都有。要重新偵測的話「分析網頁」那顆按鈕
仍然在，但它會把下面所有欄位覆寫成新的偵測結果。

改了名字的話，舊的那一份會一併收掉。

## 每個來源自己的收集設定

打開精靈的「**進階設定**」，最上面幾項是**這個來源自己的設定**，存起來之後
每次爬它都會套用——包括自動排程去爬的時候：

| 設定 | 說明 |
|---|---|
| 從第幾頁開始 / 到第幾頁 | 常用的頁數範圍 |
| **這個來源的產業** | 名錄幾乎都是一個分類一頁，分類本身就是產業。但它寫在麵包屑或頁面標題裡、不在每一列的資料中，逐列抓的規則抓不到它——填在這裡就會自動補上（頁面自己有寫產業時不會被覆蓋） |
| **要收集哪些欄位** | 沒勾的欄位在寫入資料庫前會被清空。只想要公司名稱與信箱時，多抓的地址與統編只是雜訊，還會讓「尋找重複」多出無謂的比對維度 |

公司名稱不在勾選清單裡：它是必填的，不收集就等於整筆不要。

> 「爬取」頁上的起始頁／結束頁／最多幾頁是**這一次執行**的臨時覆寫，
> 留空就照來源自己的設定跑。寫在那一頁的東西自動排程不會看到。

## 名冊是一個 PDF 或 Excel？

不少公協會沒有把會員名冊做成網頁，而是掛一個檔案在網站上，常常還要先點進
某個子頁面才看得到那個連結。

**分析網頁之後**，精靈的「要不要順便讀頁面上的檔案」會告訴你這一頁連出去
幾個 PDF／Excel／Word／PowerPoint——**只有真的有的格式才勾得動**，勾了不會
發生任何事的選項比沒有那個選項更讓人困惑。

**預設全部不勾** —— 讀別人的檔案跟讀網頁不是同一件事，該由你決定。

| 支援格式 | 怎麼讀 |
|---|---|
| `.pdf` | 有格線的表照表格讀，其餘照文字讀 |
| `.xlsx` `.xls` `.csv` | 第一列當標題，跟匯入完全一樣 |
| `.docx` | 「負責人︰王大明」這種標籤解析 |
| `.pptx` | 一張投影片一家公司，表格與文字都讀 |

- 對應不到固定欄位的欄，一樣原樣保留成「其他欄位」
- **讀出來不像廠商名冊的整份略過** —— 章程、會議記錄、年報都落在這一類
- 掃描成圖片的 PDF 會明講「沒有可擷取的文字」，不做文字辨識

## 電話藏在「顯示電話」按鈕後面？

有一類名錄的電話與信箱要按下按鈕才出現，或只先載入前 20 筆、要按「載入更多」
才有其餘的。**那些資料在原始網頁裡根本不存在**，一般爬取抓不到。

分析時偵測到這種按鈕，「**先點開頁面上的按鈕**」就會啟用，勾了之後爬取會自動
點開它們（每一列各按一次、或連按「載入更多」、或往下捲）。

> 這需要用內建瀏覽器。程式會自己判斷並記在這個來源上，不必手動切換設定。
> 比一般爬取慢很多，所以只在真的需要時才開。

## 只有查詢框、沒有完整清單的名錄？

有一類名錄不給你「全部列出來」，只給一個查詢框：選一個分類、或打一個關鍵字，
按下查詢才會出現廠商。那種頁面沒有第 2 頁可以翻——把條件逐一查過去，就是它
唯一的「翻頁」。

分析時會**數出這個選單有幾個條件**（跟偵測總頁數是同一個意思）並顯示出來，
勾「**這一頁要先查詢才有資料，幫我一項一項查**」才會執行。

* 選單型（例如 97 個商品分類）：指定要查哪一段，**預設從第 1 個往後查 3 個**
  ——先少量試跑，確定抓對了再放大。
* 關鍵字型：自己填要查哪些字，用「、」分隔，一個字查一次。

### 要查哪一段

97 個分類跑完要好幾個小時，所以本來就會分次跑——今天 1 到 20，明天從 21 接
下去。兩種指法**擇一**，選了一種另一種會反灰：

| 指法 | 怎麼填 |
|---|---|
| **用序號** | 從第 `7` 個到第 `9` 個，或「從第 7 個往後查 3 個」 |
| **用選項上的文字** | 從 `03 魚類` 到 `10 動植物油脂` |

文字那一種比較好用——你在畫面上看到的是「03 魚類…」，沒有人會去數那是第幾個。
值與顯示文字兩邊都會比對，所以打 `03` 或 `03 魚類` 都認得。

> 打錯字的話會退回序號，並在日誌裡寫明「找不到起點『xxx』這個選項」。
> 不會安靜地爬成完全不同的一段——那種錯要跑完才會發現。

起點跟「中途斷掉可以接著跑」不衝突：起點是你指定的，續跑的進度是在那個起點
之後往前推的。

### 中間還要再點一層

分析遇到查詢型頁面時會自動試查一次，用查詢結果推出欄位——還沒查詢的頁面上
一筆資料都沒有，只看那一頁是猜不出「一筆資料長什麼樣」的。

**查出來還不是廠商的話會再往下點一層。** 有些網站是三層的：選一個大分類 →
出來一張子分類清單 → 點其中一項才看得到廠商。中間那一層看起來很像資料，
裡面卻一家公司都沒有；分析會自己試著點下去，確認點下去真的有廠商才採用。

同一頁上如果**選單跟關鍵字兩個查詢框都有**，程式兩條都會試，並記下實際驗證
過走得通的是哪一條。選單那條試過查不出廠商時，畫面會直接說出來，不會給你一個
按了會白跑一下午的選項。

> 每一列都是一次往返。97 個分類 × 每個分類幾十個子分類，跑完是幾千次請求、
> 好幾個小時。這種網站建議先用關鍵字那一條，或者一次只指定一小段。

## 詳細資料是點出來的小視窗？

另一種明細：不是連到另一個網址，而是點一下公司名稱，在同一頁彈出一個小視窗，
電話、信箱、統編全在裡面。程式會逐列點開、讀完再關掉，內容按位置一一對應
回去。點不開的那一筆會留空，不會讓某一筆撿到別人家的電話。

**這件事不用你自己設定**。分析時會實際點一下第一筆看會不會跳出東西，跳出來
之後還會確認裡面真的是聯絡資料（用讀名錄的同一套去拆，至少要拆得出兩個看得懂
的欄位），連「哪一顆是關閉鈕」也一起找。認出來的話，分析結果那一段會直接寫
「這個名錄的詳細資料是點一下跳出來的小視窗」，並且列出裡面有哪些欄位。

判斷方式是「點之前看不見、點之後看得見」，不是「頁面上有沒有 class 帶 modal
的東西」——那種容器在很多網站上一直都在（藏著），光看存不存在會把 cookie 提示、
登入視窗都認成明細。

> 逐筆點開會慢很多：每一家公司都是一次往返。分析結果那一段會先提醒你。

## 「這次抓到的比上次少很多」

爬取結果表格最後多了一欄「提醒」。網站改版之後，程式抓的位置會失效——爬取仍然
會「成功」，只是一筆都沒抓到，畫面上還寫著完成。這是最難發現的一種壞掉，尤其
排程是半夜自己跑的。

程式會拿這一次跟**上一次真的有抓到東西**的那一次比：抓到 0 筆、或掉到不足四成，
就把話講出來，狀態列也會變成提醒色。看到的時候重新分析一次那個來源就好。

還有一種更難看出來的：**抓到了東西，卻一筆都沒存進去**。那不是「抓不到」——
頁面讀到了、重複區塊也找對了，是「公司名稱」那一欄指到了別的位置（子分類代號、
表頭、導覽列）。這種情況會直接寫「抓到 N 筆，但全部都不是公司資料」，日誌裡
還會印出實際抓到的文字，一眼就看得出抓錯位置。

## 暫停與取消

爬取進行中有兩顆按鈕，它們**不是同一件事**：

| 按鈕 | 做什麼 |
|---|---|
| **暫停** | 停在這裡，記住做到哪。下一次按「開始爬取」從這裡接著跑 |
| **取消** | 停下來，並且把進度丟掉。下一次從頭開始 |

逐項查詢一趟可能好幾個小時。以前第 80 個條件時網路斷一下，下次就得從第 1 個
重來。現在會記住做到哪裡，下一次自動接續，活動紀錄裡會寫明「這一次是接續上次
沒跑完的地方」。

爬的時候「公司」頁會自己長出來——切過去就看得到已經存進去的那些，不用等整趟
跑完。

> 只有「網址帶頁碼」的分頁與逐項查詢接得回去。靠「下一頁」連結一頁一頁走的
> 名錄沒有可定址的頁碼，第 5 頁的意思是「跟著連結走四次」，跳不過去。

## 抓到的東西不對的時候

打開精靈最下面的「**進階設定**」（平常收起來）。裡面可以逐欄調整程式要從網頁的
哪個位置取值，也可以新增或刪除欄位。自動偵測失敗時，這一區會自己展開。

兩個值得知道的設定：

- **「下一頁」連結的位置** — 留空就只爬第一頁
- **「最多進入幾個詳細頁」** — 很多名錄的清單頁只有公司名稱，信箱與電話要**點進去**
  才看得到。這個上限設得比公司總數小的話，後面的公司就不會有聯絡資料

> 找不到重複區塊時，通常是該頁用 JavaScript 產生內容。
> 把 `config.yaml` 的 `crawler.engine` 改成 `playwright` 再試一次。

## 抓到的公司沒有信箱？

名錄不一定會公開每一家的信箱。「爬取」頁有「**補抓信箱**」：程式會逐一連到
那些**有網址但沒信箱**的公司自己的網站，找公開刊登的聯絡信箱。

每個網站都會各自檢查它自己的 `robots.txt` 並遵守請求間隔，所以會花上幾分鐘
——按下去之前會先告訴你預估時間與公司家數。

## 這家公司還在不在？

名錄網站不會把倒掉的會員刪掉，所以一份剛爬回來的名單裡，一定混著早就解散、
撤銷、廢止的公司。

「爬取」頁的「**補公司登記資料**」會拿名單裡的**統一編號**去查經濟部商業司的
商工登記公示資料，補上：

| 補上什麼 | 放在哪裡 |
|---|---|
| 登記狀態（核准設立／解散／撤銷／廢止） | 公司列表新增的「登記狀態」欄 |
| 資本額 | 詳細資料，也是名單品質分數的一項 |
| 登記負責人、登記地址 | 只在原本是空的時候才填，不會蓋掉你自己填的 |
| 登記名稱、實收資本額、設立日期、登記機關 | 詳細資料的「其他欄位」 |

跑完之後活動紀錄會直接寫「其中 N 家的登記狀態已經不是核准設立」——那幾家
在寄開發信之前值得先確認。

幾件要知道的事：

- **這顆按鈕只吃統一編號。** 它用的那個資料集不支援名稱查詢，所以沒有統編的
  公司這一步幫不上忙，程式會照實說，不會拿名稱去猜一家給你。只有公司名稱的
  名單請改用下面那顆「補齊公司資料」。
- 對方尖峰時間會忙線。遇到就跳過那一筆，而且不會標記成「已查過」，下一次
  按這顆按鈕自然會再試一次。
- 查過的公司半年內不會重複查。

> 資料適用**政府資料開放授權條款－第 1 版**，允許商業利用，但顯名標示是強制
> 義務。所以來源標示會固定出現在設定頁、公司詳細資料，以及每一份**含有登記
> 資料**的匯出檔；沒用到這些資料的檔案不會多出這一行。

## 手上只有公司名稱和電話？

上面兩顆按鈕各自有前提：「補抓信箱」要先有網址，「補公司登記資料」要先有統編。
從展場、名片、同事給的 Excel 來的名單常常兩個都沒有——那種名單按哪一顆都會
得到「沒有需要處理的公司」，而那句話讀起來像是「已經很完整了」。

「爬取」頁的「**補齊公司資料**」是給那種名單的。一家公司走三關，每一關都只在
真的缺那些欄位時才跑：

| 第幾關 | 做什麼 | 補到什麼 |
|---|---|---|
| 1 | 查經濟部商業司（有統編用統編，只有名稱就用名稱模糊查詢） | 統一編號、登記負責人、登記地址、登記狀態、資本額 |
| 2 | 還是沒有網址的話，搜尋找出官網 | 網站 |
| 3 | 到官網上讀公開頁面 | 信箱、電話、傳真、聯絡人 |

**已經有值的欄位一律不會被覆蓋**，只補空的。你自己填的窗口、改過的地址都不會
被動到。

### 搜尋到的網址不一定對，所以會先驗證

搜尋引擎的第一筆不保證是這家公司。「大同公司」可能回大同大學，「永豐」可能回
永豐銀行。存錯的網址比留白糟得多——留白至少看得出來是缺的，錯的網址會一路帶到
寄信名單上。

所以每一個候選網址都要通過同一關：**抓下來的首頁文字裡要出現這家公司的名字**。
通不過就換下一個候選，候選用完就留白。人力銀行、維基百科、社群、購物平台這類
聚合網站在候選階段就直接排除，它們一定會提到公司名字，驗證那關攔不住。

另外兩道關卡：人力銀行、維基百科、公司資料聚合站、中小企業的虛擬主機平台
（web66、tggo 這類）整個排除；**把公司名字或統一編號放在網址路徑裡**的網址
也丟掉——公司自己的網站不會那樣做，只有名錄才會：

```
findcompany.com.tw/信邦電子股份有限公司     ← 名字
comptw.com/item/28388051                    ← 統編
inc.com.tw/c/84666583                       ← 統編
```

統編這一條查得到，是因為第一關（商業司）已經先跑完了。

跑完之後活動紀錄會寫「N 家找到了網頁，但頁面內容沒有提到該公司，因此沒有採用」
——看到那一行代表功能正常，不是搜尋壞了。

### 實際跑起來大概是什麼成績

拿台灣機械工業同業公會的會員名冊（2699 家，只有公司名稱、信箱欄全空）
等距抽 12 家實跑：

| 欄位 | 命中 | |
|---|---|---|
| 統編、登記狀態、登記地址、負責人 | **12/12** | 官方登記值，最可靠 |
| 官網 | 8/12 | 留白的 4 家是刻意留白 |
| 電話 | 8/12 | |
| 信箱 | **6/12** | 其中 5 個跟官網同網域 |
| 傳真 | 4/12 | |

每家約 8 秒——2699 家全跑大約 6 小時，而且 DuckDuckGo 會在中途開始限流，
那種規模建議先申請一把 Brave 金鑰。

> **它仍然只是「最可能的那一個」。** 寄信之前值得把補回來的網址掃一眼。
> 大公司又更難：台積電、大同、信邦三家的統編全中，但信箱 0/3——大公司的
> 聯絡方式幾乎都藏在表單後面，不是明文刊登的。
>
> 完全不想要這種不確定性的話，把 `config.yaml` 的 `completion.search_provider`
> 設成 `none`——只補商業司那一關與「檔案裡本來就有網址」的公司，那兩者都是確定的。

### 找官網用哪個搜尋來源

預設是 **DuckDuckGo**，不需要申請任何東西也不用設定。

會選它是因為 robots.txt。這支程式每次請求之前都會查對方的 robots.txt，而各家
搜尋引擎的立場不一樣：

| 端點 | robots.txt |
|---|---|
| google.com | `Disallow: /search` |
| bing.com | `Disallow: /search` |
| duckduckgo.com | `Disallow: /html` |
| **html.duckduckgo.com** | **`Allow: /`** |

前面那幾個不是「我們選擇不用」——是這支程式**自己會把那些網址擋下來**。要用它們
就得關掉 robots 檢查，而那件事這個專案不做。

DuckDuckGo 對密集查詢會限流，一次跑幾百家時後段容易被擋（程式會照實標記成
「搜尋已停止」，不會假裝有結果，而且商業司那一關對剩下的公司仍然照跑）。遇到
那種情況，到「設定」頁的「**搜尋官網（選填）**」填一把免費金鑰就會自動改走
官方 API：

- [Brave Search API](https://brave.com/search/api/)——免費方案每月 2000 次
- [Google Custom Search](https://developers.google.com/custom-search/v1/overview)——免費每日 100 次，另外還要到 [Programmable Search Engine](https://programmablesearchengine.google.com/) 建一個搜尋引擎取得 ID

金鑰跟 Gmail 密碼一樣存在作業系統的憑證保管庫，不會寫進專案資料夾裡的任何檔案。
完全不想搜尋的話，把設定頁的搜尋來源改成「不搜尋」，其餘兩關照樣有用。

### 匯入完自動接著補

「匯入」頁有「**匯入後自動補齊資料**」的勾選框，勾了之後匯入完成會接著對**這一批**
公司跑一次補齊，不會動到資料庫裡既有的資料。

預設是關閉的，而且應該保持關閉當預設：補齊會連網，匯入 500 筆就是 500 次以上的
請求，那件事該由你自己按下去。單次自動補齊有家數上限（預設 200），超過的部分
會照實告訴你，請到「爬取」頁自己按按鈕處理。

### 命令列

```bash
python main.py complete                      # 全部補一輪
python main.py complete -n 50                # 只處理 50 家
python main.py complete -f website,email     # 只補這兩個欄位
```

## 直接寫設定檔

在 `config.yaml` 的 `crawler.sources` 加一段：

```yaml
- name: "my_directory"
  type: "generic_html"
  enabled: true
  start_url: "https://example.com/list?page={page}"
  max_pages: 5
  list_selector: "div.company-card"
  pagination:
    type: "query"            # query | next_link | none
  fields:
    company_name: { selector: "h3.name" }
    email:        { selector: "a[href^='mailto:']", attr: "href" }
    phone:        { selector: ".tel" }
    website:      { selector: "a.site", attr: "href" }
    address:      { selector: ".addr" }
    industry:     { selector: ".industry" }
    tax_id:       { selector: ".tax-id" }
```

每個欄位還支援 `regex`（從值裡再擷取一段）、`multiple`、`separator`。
